# 音樂與語音 HD 評估

本輪依使用者要求作可行性評估，沒有把新音樂或配音加入遊戲。原始資料為本機固定來源，唯讀盤點工具為 [inspect_original_audio.py](../tools/inspect_original_audio.py)，記錄在 `workplace/original-audio-v1/inventory.json`。位址皆為來源檔案 byte 偏移。

## 音樂

`SF000.MUS`，172,513 bytes，SHA-256 `78af89020939bc7f2013f3869332aae1a67a2600c14ec7820146599e31cdaeda`。它由十五段完整 Standard MIDI File 相接，皆為 format 0、一軌、每四分音符 240 ticks。這些是已證實的格式事實；每首對應的場景與遊戲內切歌時點尚未驗證。

可以保留原旋律、節奏及配器指令，用成熟 MIDI 播放器與較好的音源重播，再製作音量一致、可循環的 OGG。這能提高音源品質，無法把後來選用的音源稱為原 DOS 音效卡的相同音色。正式接入前仍需確認各首用途、循環邊界、音源選擇、切歌契約及原版／HD 切換。

本機推廣片使用原檔逐段切出的 MIDI，再以成熟軟體音源重播。這是原版 MIDI 配樂，沒有改寫旋律；它是軟體重播版本，沒有聲稱 DAC／OPL 實機錄音。影片與音訊只留本機，不隨 Release 提供。實際播放器、音源 SHA-256、輸出格式及非靜音檢查另記在影片來源紀錄。

## 語音與音效

`FIV-*.PPM` 含有 `Compact PCM File` 標記與指向各記錄的檔內位移表。標記、記錄邊界與逐組 SHA 由工具直接驗證，不能只依副檔名推定圖片或音訊。payload 常見 88h 附近資料，四位元 PCM 是格式假說；取樣率、解碼方式、每段是否為語音或音效，以及對應角色仍未證實。

若保留原錄音，可先確認解碼，再評估降噪、去直流、音量及有限的頻寬修復。升到 48 kHz 不會補回原來缺少的聲音細節。重新錄製則涉及音色、台詞、表演與權利的選擇，須先聽對照樣本再定案；本輪不自行套用配音或聲音複製。

## 接入停止線

先取得最小充分的曲目／語音用途及原版播放完成契約，再擬接入規格。硬體時序採已知平台規格與成熟工具，不逐週期追 DAC／PIT driver。語音格式尚未確認時保留未知，不把試聽猜測寫進正式資料。桌面音訊串流、完整切歌及人耳驗收目前仍未完成；這份評估不代表音樂／語音 HD 已上線。
