## 操作與記號

青衫列出的鍵盤配置如下。SP Moves 的 P、K 是拳與腳的動作代號，不是要求按鍵盤字母 P、K。

| 動作 | 第一人 | 第二人 |
|---|---|---|
| 左上、上、右上 | Q、W、E | 數字鍵盤 7、8、9 |
| 左、右 | A、D | 數字鍵盤 4、6 |
| 左下、下、右下 | Z、X、C | 數字鍵盤 1、2、3 |
| 拳 P | Tab | Enter |
| 腳 K | 左 Shift | 右 Shift |
| 防禦 | 後退 | 後退 |
| 選單確認 | Enter | 共用選單操作 |
| 暫停／離開 | Esc | 青衫同時記載按住補血的密技，兩種用途須分辨 |

- 以下方向均以角色面向右為基準，換邊時左右反轉。
- `＋` 表示同時按，連寫方向表示先後輸入。
- `蓄` 表示持續按住。青衫另記載某些蓄力可用連按三次代替，這是來源說法，尚未逐招實測。
- 青衫的「蹲」包含左下、下、右下；「跳」包含三個上方向。「移」包含往前或往後的移動。
- 近身、空中、蓄力等條件一併保留，不能只看最後一個攻擊鍵。

## 青衫的規則與資料研究線索

以下均是青衫的整理，不把攻略陳述直接升格為目前執行檔的已驗規則。

| 主題 | 來源記錄 | 本專案用途 |
|---|---|---|
| 生命與暈眩 | 初始生命 124；短時間累積傷害超過 40 可能暈眩；生命會緩慢回復 | 正常對戰驗證候選，不直接寫成前端規則 |
| 防禦 | 一般攻擊可擋，投技不能靠防禦抵消 | 原版實測候選 |
| 多段攻擊 | 各段需要實際命中，不能只把總傷害當固定結果 | 不由快捷鍵保證命中或傷害 |
| 特殊技資料 | SFMAN??.DAT 的 0600h 附近，12-byte 招式記錄，含姿態條件與反向保存的按鍵序列 | 檔案偏移線索；需由目前版本的讀取端核對 |
| 按鍵位元 | P=10h，K=20h，右=01h、左=02h、下=04h、上=08h；80h 有任一條件的用途 | 不與鍵盤掃描碼混為一談 |
| AI 作弊檔 | 用 CHEAT 目錄資料替換後，對手較少主動攻擊，近身仍可能攻擊 | 只作受控研究；不覆寫正常來源 |
| 其他修改 | 原文保存了版本相關的保護、角色、勝負與計時修改資料 | 原始快照可回查；本表不搬用不明版本的修改位元組 |

青衫還保存了逐招基礎傷害、特殊技分段傷害及說明；完整數值留在 [原文快照](../workplace/manual-reference/sf.htm)。此整理著重操作、來源差異與可追溯入口，不把尚未實測的傷害表當成 remastered 規則。
