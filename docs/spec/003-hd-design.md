# 003：HD 美術與呈現設計草案

狀態：DRAFT。日期：2026-10-19。畫風已採 B「街機手繪」，倍率、預設模式與量產範圍尚未定案。這份文件規劃原版核心之上的呈現層，沒有接入遊戲。

使用者後續明確回覆「我同意 hd規格開工吧」，已授權依本規格開工。首批採下文的屋頂、斬、法蘭克與對戰介面切片。設計與切片範圍已確認；格式、繪製來源、完整動畫與正式呈現仍有技術未知，規格不因此自動升為 READY。

## 本輪實作入口

- [分層預覽](../../tools/hd-preview.html)：1600×1000 的素材組合試作，使用背景、兩名角色透明待機圖與獨立展示介面；沒有遊戲核心，數值不代表對局狀態。
- [場景來源蒐證](../../tools/hd_source_probe.py)：由來源 bytes 解出 11 張 XGB 與 3 張 CPM。屋頂候選為 I2.XGB，抽樣 700 點中 633 點在位移 80、0 一致；不是整張畫格或動畫 parity。
- 證據與接觸表位於 `workplace/hd-source-probe-v3/`。SFNAME.CPM 的 header 不符合目前候選，保留 unknown，不套用同副檔名推測。
- 原版姿態圖集已解出斬與法蘭克各 72 槽，分別有 61／57 個不同圖像位置；逐圖、指標與雜湊在 `workplace/sprite-source-v1/evidence.json`。候選格式為強推論，runtime 繪製來源鍵、鏡像及錨點尚未閉合，不能由圖集直接宣稱 D1 完成。
- 分層素材與提示詞位於 `workplace/hd-layers/`。背景實際 1923×818，兩張角色有真實 alpha；它們是原型，不是已對齊或可發布的完整素材包。
- 缺少姿態的示範會整張顯示固定的原貌收據，不能把此示範當成正式動態回退已完成。

## 兩種比較方向

| 方向 | 設計 | 適用與代價 |
|---|---|---|
| A 忠實精修 | 高解析像素繪，保留原色彩與造型，以更細像素群補服裝、表情及建物細節 | 接近原作；動畫須維持一致像素密度，不能只做濾鏡放大 |
| B 街機手繪 | 1990 年代街機插畫、清楚墨線與色塊陰影，角色與背景分層重繪 | 服裝與表情更清楚；所有姿態需統一比例與線條，動態接縫風險較高 |

共同輸入是同一張首戰截圖。生成圖是構圖參考與畫風試作，角色比例、姿態、生命條或背景細節仍可能偏移，不稱為同狀態 HD 驗證。原貌截圖保留在旁供比對。兩稿由內建 imagegen 生成，最終提示詞、原始輸出與 SHA-256 保存於 `workplace/design/`。

本輪實際生成尺寸均為 1586×992，並非要求的 1600×1000。兩稿均出現未核實的長髮、破褲與肌肉細節，腳底及背景比例也未逐點對齊。比較時只選美術方向；這些差異須依原版修正，不隨畫風選擇自動定版。

## 畫布、介面與動態

| 項目 | 草案 |
|---|---|
| 邏輯座標 | 原版 320×200 保持不變；本輪概念稿要求 1600×1000，只是 5 倍的比較畫布，實際生成尺寸以 manifest 為準 |
| 顯示比例 | 原始資料比例 8:5 與傳統 4:3 顯示分開處理；正式像素比例及預設值待確認，不直接拉寬或裁切成 16:9 |
| 寬螢幕 | 以外框承載操作提示；不增加核心可見場地、不移動碰撞與鏡頭邊界 |
| 角色 | 以原版已證實姿態與繪製來源索引覆繪，保留根錨點、面向、透明及前後遮擋 |
| 背景 | 屋頂先作一個可驗場景，保留地平線與主要建物；不添加會誤導距離的可互動物件 |
| 戰鬥介面 | 生命條、計時、名字、回合與勝負訊息分層重繪；數字只讀核心狀態，不由截圖猜測計算 |
| 選角 | 保留原有角色順序、名稱與可選狀態；HD 頭像與游標重新繪製，鎖定角色不因美術存在而解鎖 |
| 標題 | 紅金中文字標與紫色人物分層；單打、雙打、設定、結束保持原有流程 |
| 招式說明 | 前端顯示方向、拳、腳與蓄力標記；對局不代按，換邊說明清楚標示 |

| 原貌切換 | 同一核心狀態下切換呈現，不能重新開局或改寫遊戲狀態 |

## 驗收界線

### D1 部分閉合回填

背景與完整畫格的未知已由[規格 006](006-rooftop-background.md)部分閉合。固定 SHA-256 的 SF.EXE，IDA MZ 線性 `sub_13DE4` 已證實背景來源與步幅，`sub_13E5C`／`0x13E9D` 已證實完整顯示拷貝觀測點；`sub_141FA`／`sub_1439B` 及 DS:16F2h／16FAh 已核對本輪取樣姿態指標與原始圖像 bytes。006 的背景試作保留整套原貌前景，不依賴待機圖覆蓋動作。

此回填不閉合完整角色姿態、鏡像錨點、HD HUD、正式倍率與預設模式。規格 003 維持 DRAFT。現行線性 API 未套用硬體 CRTC 起點，限制沿用 006；不能由本切片推論實機震動 parity。

- 概念圖只檢查方向與辨識度。生成圖的人物細節及文字需人工修正，不能直接當完整動畫資產。
- 正式資產需記錄來源鍵、雜湊、尺寸、根錨點、鏡像、透明、遮擋、使用範圍與權利；格式在 D1 後依規格流程定案。
- 動態驗證比較同一核心狀態的原貌與 HD，分開檢查遊戲行為不變及美術符合定版。
- 本輪不宣稱 HD 引擎、動畫、實體手把或可發布套件已完成。
