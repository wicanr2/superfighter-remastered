# 008：HD 角色分層與完整動作

狀態：READY，限定下列已驗來源、翻轉與裁切的原生角色呈現契約。日期：2026-10-19。DRAFT 已依 716 格原版分層及姿態比較審查；完整角色、其他場景與 HD HUD 仍未完成，不能以本規格的局部實作代替整個 Goal。

## 目標與完成範圍

將已確認的 B 街機手繪角色接入原版完整畫格。保留原版姿態選擇、幀序、時長、位置、朝向、鏡像、裁切、遮擋與出招條件。首批製作斬與法蘭克，補齊完整動作後再擴充其他正常流程可見角色；首批不是整個 HD Goal 的完成分母。

目標不以待機圖、局部換色、最近鄰放大或單一姿態代替完整動畫。缺少已驗來源、動作或色盤時回退是保護措施，不能因此把未完成項記成完成。

## 固定原始來源與位址

SF.EXE SHA-256：`24b23d41c5fe6015d211b601e44b4e030677363f7232adcf9999c9ddd80d8300`。斬 SFMAN01.DAT：`da5de4b2f997e411582949c2f0ab2f0540324f1e83d90bd282b78b2901a860b9`。法蘭克 SFMAN05.DAT：`b5b77d590420b92db2d265aa89483de70d58193caf442fd41eba338eb111d653`。使用時逐檔核對，不由角色名稱猜圖像。

| 原始定位與位址空間 | 證據與限定結論 |
|---|---|
| IDA MZ 線性 `sub_141E0`，DS:1335h | 兩名角色的呼叫次序由原版決定；不自行把第一人固定畫前面 |
| IDA `sub_141FA`／`sub_1439B`；runtime `01B9:42A5`／`01B9:4446` | 每名角色的主圖像呼叫與繪製後觀測點，之後另有特效；不能只移除角色色盤範圍 |
| IDA `sub_14665`／`sub_146E8`／`sub_1477E`／`sub_1480A` | 高 nibble 先、零透明的 4bpp 繪製，包含翻轉與成對像素裁切；原始 bytes 在 ida-hd-draw-v2 |
| runtime 四支 blit 入口的 ES:DI、BX、CX、DX、DS:SI | 讀取目的起點、左右／上方裁切、翻轉、色盤與來源指標，不改暫存器 |
| runtime `01B9:3DE4` 至 `01B9:3E9D` | 依規格 007 觀測軟體合成 RAM 的每次寫入，重建完整畫格；顯示 API 的 CRTC 限制沿用 006 |

靜態工具為 IDA 9.4、MZ 映像段 1000h；runtime、DS 偏移與檔案偏移分開記錄。來源圖像表的檔案偏移為 AC8h 色盤、B28h 指標表、C48h payload，relative segment×16＋offset。原始定位保持不改名。

## 正常路徑已證實範圍

`tools/sprite_draw_receipt.go` 走正常標題、雙打、斬／法蘭克選角，再以方向、蹲跳與拳腳操作，沒有注入座標、姿態、勝負或亂數。

- `sprite-draw-v1` 與 `sprite-layers-v1` 各記錄 1,432 次角色主圖像繪製，每次預測後的 64,000 個畫面像素均與 CPU 實際寫入相同，來源完整 bytes 也全部吻合。
- 兩輪 1,432 次繪製的角色、姿態、位置、尺寸、旗標、指令數、計數器與來源指標均相同。新增的觀測沒有改變這條玩家路徑。
- 分層輪取得 716 個完整畫格，每格五層。依原順序重組的 716／716 格逐點相同，底層 64,000 像素全覆蓋，並保留 37,424,320 次同值重寫。
- 已動態覆蓋 flags 00h、40h、80h，以及左右邊界裁切。C0h 同時翻轉與負 Y 頂部裁切尚未有本輪動態樣本，不能由前三種升格為全部已驗。

## 呈現資料流草案

1. 從背景重畫開始記錄 RAM 寫入，建立第一個原貌 raster 層。
2. 每次角色主圖像呼叫建立獨立角色層，保存已驗來源鍵、完整來源尺寸、原版位置、翻轉與裁切。
3. 主圖像之後的陰影、投射物、特效、文字與 HUD 寫入保存在後續 raster 層。即使值沒變也保留覆蓋位置。
4. 完成顯示拷貝後驗證分層重組與線性原貌相同，才接受完整快照。未知來源、缺少完整底層或重組不符時整張回退。
5. 呈現時依同一順序畫背景、原貌 raster、HD 角色及後續 raster。不能先畫完兩名 HD 人物，再將所有特效一律蓋到最上方。
6. 正式角色素材只選取原版當幀來源對應的重繪姿態；不重新計算動畫、猜姿態或改原版記憶體。切換、設定與雙人輸入沿用原生入口。

正式玩家路徑直接讀原版完整快照，不讀研究收據。下列型別、素材及回退契約經本輪證據審查後定為第一版；比較工具維持可丟棄。

## 第一版實作契約

原生首版五層已通過 13 項 GUI，但保留整條原貌 HUD 區域也保留了天空帶。實作審查發現這會遮到高跳角色，故先回到契約補證：既有 IDA `sub_13DE4` 的 `0x13E07` POP DS、`0x13E08` RET 精確界定背景複製結束。第一版正式快照改為六層，純背景完成後另開原貌層，直接保留實際 HUD 寫入，取消整條畫面覆蓋。此修訂仍不重繪 HUD，不改遊戲。

- `internal/renderdata` 保存 `Sprite` 與 `Layer`。Sprite 包含玩家、角色、slot、原版 X／Y、來源寬高、flags、色盤基底、上／左／右裁切與完整 packed bytes 的 SHA-256。Layer 是原貌點陣層或一個 Sprite，均保存實際寫入的色號及覆蓋位置；第一層另標記 Background。
- Core 僅在明示載入角色素材時啟用分層觀測。背景重畫時開啟，在 runtime `01B9:3E08` 關閉純背景層，完整拷貝後停止觀測，場景離開及 Close 時取消。IRQ 重訪同一入口不得新增重複層；只有純背景完整、兩名玩家各一次且重組逐點相同的六層快照可標記完整。觀測不修改原版或輸入。
- `Presentation` 附上 Layers、LayersComplete 與失敗原因。色號與覆蓋陣列不寫入一般 JSON 觀測檔。暫停或同一完整畫格的 IRQ 重訪可沿用相同且已驗快照，不以未完成畫格混合新舊角色。
- 原生入口新增選用 `-hd-characters <目錄>`，須搭配已驗背景素材。未指定時沿用 006；指定後 HD 模式必須同時具備完整背景、兩名角色與所有已知層，否則整張顯示同一快照原貌。預設仍原貌，既有視窗比例不變。
- 角色素材清單 version 1、kind `original-draw-characters`，列出 Sources、Atlases、Poses。Source 記錄角色、原檔名及 SHA-256；Atlas 記錄相對檔名、原 PNG SHA-256、寬高；Pose 記錄角色、slot、來源寬高、檔案偏移、packed SHA-256、atlas 與 alpha 邊界矩形。載入須重新核對合法原版檔、72 槽指標、寬高與完整 bytes，不能只相信清單數字。
- PNG 保留生成 bytes。準備工具只計算 alpha≥16 的矩形並複製檔案；繪製直接使用高解析區域映射至原版圖像矩形，鏡像與裁切使用已驗起點。相同原始圖像的別名槽可指向同一張已重繪姿態。
- 載入先驗全部清單、相對檔名、檔案型態、雜湊、尺寸、矩形及來源，再一次接受素材群組。拒絕重複鍵、越界、損壞、未知版本及來源不符。原版資料不複製進程式或公開包。
- 初版只接受 flags 的幾何部分 00h／40h／80h、TopClip=0，以及與來源正常色盤相同的 C0h／E0h。C0h 同時翻轉、頂部裁切或其他色盤整張回退，不猜補。來源 6-bit 色盤採 `(v<<2)|(v>>4)`，已與兩人初始 runtime 的 16／16 個 RGB 全部吻合。
- 純背景層須逐點吻合相機位移後的原始背景，才替換 HD 圖。其餘點陣與角色依原版層次繪製，保留實際原貌陰影、HUD 及特效寫入，包含同色重寫。不能以整條 48 列原貌畫面覆蓋角色；HUD 重繪另依已驗數值接入，本版 HUD 仍為原貌。
- 原貌／HD 切換只改呈現旗標，不 Step、不重開局、不改亂數或釋放操作。兩人手把、鍵盤、四格快捷與設定檔格式沿用原規格。
- 驗證包括原版 fixture 重組及鏡像／裁切幾何、素材損壞與來源拒絕、原生正常雙打的姿態變更、同狀態切換、原貌 HUD、兩人輸入、R1 與設定保存；三平台二進位重建。完整動畫與未支援狀態仍列待辦。

## 現有素材與比較稿

內建 image_gen 已生成斬與法蘭克各兩組，共 48 個姿態。原始 PNG、逐組提示詞、來源指引與雜湊位於 `workplace/hd-sprite-art-v1/`。四張 PNG 皆為 1448×1086 RGBA，4×3 等分格，具有真實透明 alpha；不修改生成圖 bytes。

角色依原版修正為斬的短黑髮／黑腰帶、法蘭克的藍色背心／灰白護腕與靴子。原版姿態參考在 `hd-sprite-reference-v1`／`v2`，不是把放大像素圖稱為 HD。

`tools/hd_actor_preview.go` 的 `hd-actor-preview-v3` 比較 16 個已保存狀態，其中 15 個有兩名角色的對應素材，1 個缺斬 slot 56 而不畫半套 HD。涵蓋待機、移動、普通攻擊、蹲、跳與空中姿態；它是離線原版分層比較稿，不是原生 GUI 或完整動畫驗收。

比較稿依每格 alpha≥16 的邊界註冊到原版圖像矩形，依原版鏡像的加一像素起點與成對裁切定位。相機目前由完整背景的唯一吻合位置取得，只供比較稿；正式路徑必須直接讀取 runtime DS 與來源雜湊。素材透明邊緣、跨姿態比例、完整動作與受擊替代色盤仍須檢查，不由縮圖或格式測試升格為完成。

## 下一個閘門與停止線

- 補齊兩名角色的其餘動作、倒地、特殊技、相關特效與替代色盤。先做來源、姿態及錨點已足夠的部分，不再深挖不影響 HD 的 executable helper。
- 用正常原生玩家路徑接入完整分層快照與角色素材，驗證同時操作、換邊、遮擋、場邊、受擊／倒地及同狀態切換。缺件回退與設定保存分開驗。
- HD HUD 必須讀原版已驗生命、計時、姓名與回合資料，不能由截圖猜數值。
- 所有正常流程可見角色、背景、標題／選角／結果介面及動畫的 HD 完整度，均納入 Goal 的後續完成核對。正式倍率與預設模式仍沿用 003 的待定狀態，首批不能替代全目標。
- 三平台建置與實跑證據分開；實體雙手把、Windows／macOS 真機與音訊不因圖像比較通過而自動完成。
- 原版及衍生 HD 素材仍留本機，不加入 Git 或一般發行包。
