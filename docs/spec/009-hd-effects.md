# 009：原版順序的 HD 特效

狀態：READY，限定下列來源、第二組色盤及未裁切的已驗特效。日期：2026-10-19。範圍沿用已確認的 B 街機手繪 HD；只替換已核對的來源與色盤，不改出招、碰撞、傷害、動畫或存檔。

後續[043 主色盤額外圖像](043-primary-palette-extra-sprites.md)另補證鬼丸來源 35 的 C0h／E0h、第二人 4523h 返回及同角替代色盤。009 的第二色盤取樣限制保留；`Sprite.Effect` 代表額外繪圖，不能再單由此欄推定 bank 1。未驗主色盤呼叫仍拒絕。

## 原始證據

SF.EXE SHA-256 為 `24b23d41c5fe6015d211b601e44b4e030677363f7232adcf9999c9ddd80d8300`。SFMAN01.DAT 為 `da5de4b2f997e411582949c2f0ab2f0540324f1e83d90bd282b78b2901a860b9`，SFMAN05.DAT 為 `b5b77d590420b92db2d265aa89483de70d58193caf442fd41eba338eb111d653`。dosgolem 1715 檔來源沿用 008 的固定 manifest，共用來源不改。

- `effect-draw-v1` 正常標題／雙打後送斬的天雷、旋風與鐵頭輸入，527 次 blit 的繪製後像素與每次覆蓋位置均吻合，254 個完整畫格按原順序重組逐點相同，沒有未實作指令。
- `effect-draw-v2` 正常雙打的跳躍與兩組法蘭克方向／拳輸入取得 488 次吻合 blit、229 個完整吻合畫格。第二組輸入未證實同一招式，不將嘗試的按鍵當成快捷已驗證。
- 合計 1015 次 blit、483 格。角色主圖像 966 次，特效 49 次。全部特效來源指標吻合對應玩家的 72 槽 RAM 表，完整 packed bytes 與原檔吻合，等值寫入的覆蓋位置也吻合。此為已證實的取樣範圍。
- 斬特效槽為 45、46、47、48、57、58、59、60；法蘭克為 12、37、43、55、56。實際色盤均吻合原檔 AF8h 起的第二組 16 色，6-bit 轉 8-bit 使用 `(v<<2)|(v>>4)`。斬原始色盤基底為 D0h，法蘭克為 F0h；先前以 AC8h 正常人物色盤畫出的褐色／金色特效不採用於 HD 特效。

位址空間：runtime `01B9:offset`，原檔偏移另列。原 `sub_14665`／`sub_146E8`／`sub_1477E`／`sub_1480A` 對應 runtime 4665h／46E8h／477Eh／480Ah。已取樣特效的 near-call 返回點為 4393h、45AFh、4618h。返回點表示呼叫位置，不等於來源玩家。

來源玩家先由已核對的 D0h／F0h 判定，再逐一比較 DS 相對 1706h／1826h 的 72 槽指標加上 132Ah／132Ch 基底。對上實際 DS:SI 後選相同來源的第一個別名槽，保留完整 bytes 雜湊。不能由特效出現在誰旁邊或呼叫函式名稱猜玩家。

## 呈現與相容契約

- 原六層為無特效時的基底。新版素材啟用特效時，每個已證實的特效 blit 拆成獨立 sprite 層，後面另開原貌層，保持每次實際寫入的順序。每格仍須兩名主角色各一次、純背景全覆蓋、完整重組吻合。最多 16 個特效，總層數最多 38。
- `Sprite.Effect` 只標記特效。主角色仍沿 008 的定位；特效由 ES:DI 相對合成緩衝區的原始目的位置取得 X／Y，使用同一個已驗鏡像起點及尺寸。取樣特效只支援 flags 幾何部分 00h／40h，且上／左右裁切為零。其他情況整張回退，不能由未取到的場邊樣本宣稱支援。
- 素材清單版本 2 為版本 1 的可選擴充，Pose 增加 `palette_bank`，預設 0 表正常人物，1 表特效。新版播放器同時接受舊版 1；版 1 不接受非零 bank。來源檔、原始 bytes、PNG、矩形與整組拒絕規則不變。正常人物與特效相同來源可分別登錄，避免把錯色圖片當成合格特效。
- 只要素材包含 bank 1，原生播放器才開啟特效分層。原版 1 素材沿用六層及原貌特效，不改已驗的操作、設定或快捷。沿用原貌／HD 角色按鈕，沒有新增玩家操作步驟。
- 已辨識的特效若缺素材、色盤不符、來源不符或幾何未支援，整格原貌回退。未辨識的其他原貌繪製仍留在原序的點陣層，不猜補來源。
- HD HUD 不在本規格內。原貌 HUD 與其他原貌寫入按層順序保留，不能以固定矩形抹除原特效或將全部 HD 特效蓋到最上層。

## 審查與驗收

RAM 指標、兩組來源檔、第二組色盤、1015 次 blit 及 483 格完整重組已審查。Python 另獨立重組兩份收據的保存畫格，全部相同。依此限定升 READY；新 HD 圖仍須載入驗證及正常原生同狀態驗收，未驗部分不進呈現。

實作驗收包含真實特效 fixture 的幾何與重組、舊版素材相容、未知 bank／色盤／裁切拒絕、正常原生 R1 路徑、特效同狀態原貌／HD 切換與 PNG 核對、兩人輸入及四格設定回歸。三平台重建與逐目標來源收據分開保存，Wine 不代替實體 Windows 或手把。

原版及衍生素材只留本機。13 種取樣來源不代表全角色、全招式、HD HUD 或完整 HD 已完成。
