## 接入契約

- 原版實際顯示優先：最後一次完整拷貝後的直接 VRAM 文字也要進入同格快照，不能只換 HD 而讓原貌遺漏文字。
- `Core.EnableVictory` 明示啟用只讀觀測。最終介面重建的 `33F4h` 入口只在返回位置 `5E77h`、原快照圖層完整且 RAM 與原快照逐點相同時重開光柵觀測。深複製原圖層，暫存字圖與新介面均記入最後光柵層；原背景、角色與既有不可變快照不改寫。其他條件不猜補圖層。
- `VictoryState` 保存原計數、回合、winner word、模式、兩角色、生命與原 `3EB7h／3EB8h` bytes。`VictoryDraw` 保存 NAME 槽、來源 DS:SI、呼叫返回位置、目的 X／Y、寬高、BH 色盤、原始 bytes 與 SHA-256。`VictorySnapshot` 保存這些值、完整標記及直接繪製前的最後光柵層。
- 入口 `3963h` 固定此次底圖與原狀態。helper `3685h` 至 `36AEh` 依原 byte／低四位透明／OR BH 重組，每次返回讀取真實 VRAM 核對。保留來源，不能靠圖像差異推覆蓋。部分繪製與未知分支也更新原貌快照，避免顯示停在文字前。
- 每個 helper 返回後及 routine 返回 `3A3Fh` 後，以真實 VRAM、色盤及顯示視窗更新原貌。原分支的完整圖像數為一般名字加 WIN 兩張，其餘一張；只有圖像數、底圖、定位、色盤及原圖層仍吻合，才在原最後光柵層的複本合併直接繪製，附上完整 `VictorySnapshot`。這也保留進入 bonus 前已完成的 YOU WIN。下一次正常畫格不沿用勝負 metadata，bonus 後若底圖已變則原貌回退，離開對戰清空。
- HD 延用已確認的高解析戰鬥字圖，位置由原版來源矩形與規格 015 的當格映射導出。缺來源、未知分支或不完整觀測時保留同格完整原貌，不猜補文字。
- HD 來源核對包含原 NAME 檔 SHA-256 `60c0bbe367e44ab9fda512df2ba93ad62d70147df90079d07ff15818f21bad82`、原字圖、原呼叫端、完整位置與介面色盤；把原字圖覆蓋還原為其下方最後光柵層後，再依原矩形繪製金色高解析字圖。名字沿用現有斬／法蘭克呈現，其餘角色仍依整格原貌。特殊字圖可依已解的原分支驗證，正常樣本與生命週期驗收仍分開記錄。
- 原版核心仍決定勝負、等待、回合切換與結果；本專案不新增勝負規則、不改等待，也不把顯示快照當遊戲存檔。玩家設定格式不變。
