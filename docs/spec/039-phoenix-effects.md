# 039：鳳凰普通攻擊光效 HD

狀態：CONFORMED，限定 Linux 正常拳腳兩光效及舊包回退。沿用版本 3 的 palette_bank=1 特效登錄，不改資料格式、輸入、傷害、幀序或時長。只補正常動作取樣已發現的鳳凰 58／60 光效，其他招式及完整動畫另驗。

## 原始來源及問題

SF.EXE 為 CONTEXT 固定 SHA，原檔 SFMAN04.DAT 的完整身分以 source-manifest.json 與本次審查綁定。普通雙打 3／4 的 hd-motion-coverage-v1 連續選角、移動、蹲跳及拳腳，已觀察 effect=true／palette_base=D0h 的槽 58／60，缺件使整格原貌。這是實際繪製事件，不能將一般 palette_bank=0 的同槽素材當作特效。

來源是 SFMAN04.DAT 實檔 B28h 的 72 指標表及 C48h payload，4bpp 高 nibble 先、零透明；第二組 16 色從實檔 AF8h 起。槽 58 為 22×25、實檔 148526；槽 60 為 32×40、實檔 152727。以上是檔案偏移，非 IDA 線性位址。

原版來源重組與正常層覆蓋／色號、原貌畫格、實際 flags／clip 與時序須獨立核對。畫稿沿 B 街機手繪，保持白／青外緣、藍紫內部、原剪影及左右朝向，不加角色、傷害數字或擴大特效邊界。

## 閘門與資料鏈

先保留生成原 PNG、精確請求、實際尺寸／透明度及來源 SHA，登錄透明區域，不修改生成 bytes。保留舊 1483 鍵／66 PNG，只新增兩個已驗特效鍵，圖集總像素與清單大小仍須低於現行載入限制。原檔 → CharacterPose 的第二色盤鍵 → 原版特效層次 → 既有 GPU 合成；來源不符、未知色盤或缺件仍整格回退。

來源及姿態審查通過才升 READY。驗真實群組及未知／損壞拒絕、正常原生出拳與同狀態切換、缺件整格原貌，並核對四平台現行編譯輸入。美術資料擴充不假稱重新編譯或 Windows／macOS 真機驗收。無新增持久資料，不修改既有鍵盤、手把或招式設定。

## READY 審查

SFMAN04.DAT SHA-256 為 2cd299e9c10814ae37bb044c2e3ae7adf940d8b1accd8feffa3844bbfb43356b。phoenix-effects-source-v1 的獨立驗證已確認兩種正常光效的原檔、第二色盤及 CPU 覆蓋／色號，審查綁定於 phoenix-effects-art-v1/evidence-review.json。生成原 PNG 為 1774×887 RGBA、alpha 0 至 255，SHA 為 3f02eaff747f18818c3ad46a8bc2aad38454c79918e0a7652f57ee6988bc76c7；兩區完整隔開，圖形及朝向已目視核對。登錄後總像素 104,196,077，低於現行 100 Mi 像素；不修改資源上限或圖像 bytes，可進實作。

## 限定接入結果

現行包新增兩個第二色盤鍵，為 1485 鍵／67 PNG／二十一來源，manifest SHA-256 為 2557a3bc5136cd8ff403632f28e161c7d9c1aacd82c3984dbcdf0079ea0c9a8d。舊 1483 鍵及 66 PNG 保持；總像素 104,196,077，manifest 517,863 bytes，皆低於現行上限。

已證實於正常核心取樣：phoenix-effects-comparison-v1 的 437 格，同格比較舊／新群組，15 格缺件已補齊，選擇成功由 418 增至 433；四格場邊幾何仍保守回退，沒有以補素材放行。獨立來源重組確認兩種光效的原檔、色盤與 CPU 層。這是 selector 取樣，不代表全部 GPU 動畫。

Linux phoenix-effects-native-full-v1／missing-v1 各八張，普通選角、移動、拳腳取得 60／58 光效。兩案的完整原檔、圖層、HUD、陰影與 CRTC 重組通過；每種光效的 HD／原貌／恢復維持原狀態，恢復逐點相同，解除暫停後回正常站立 HD。新光效覆蓋內可見變動點為 7,245／2,862；舊包兩種光效都整格原貌。來源分別為 805／318 個原始寫入點，另目視圖形、朝向及層次。

真實 67 PNG 群組及兩份正常 fixture，未知槽、壞來源、錯色盤基底及色號變更均整格拒絕。可用 internal／cmd 測試與 vet 通過。四平台仍使用 038 的相同二進位與 44 份編譯輸入，本輪只擴素材，沒有重新編譯或發布新包。

未驗：其他特效、第二人、所有姿態與時序、同角色替代色盤、Wine／Windows／macOS 真機及實體手把。十一人取樣另發現場邊 C0h／odd clip 與同角色色盤差異，仍列後續問題，不以本規格替代完整 HD 完成。
