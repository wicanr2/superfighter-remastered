## READY 來源審查

已證實：IDA 9.4 的 sub_13C38，13D7Ch／13D7Fh 比較原 ds:12ACh／12AEh，13D83h 在不同角色時返回。相同時 13D85h 的 DX=3FE8h 指向 man.col；13D93h..13DA6h 按角色乘 30h seek，13DABh..13DB9h 讀 30h bytes 至 ds:2E8h。只有第二人主色盤被替換，緊接的特效 16 色沿角色 DAT。原始函式及 caller、bytes、DS 相對運算元保存在 duplicate-palette-research-v1/ida-v2.json；檔名字串沒有自動 xref，引用由 operand 與 IDA 資料段基底 1A410h 核對，不假稱直接引用。

十一種正常同角色雙打，待機與雙向行走各一份，共二十二格。第一人 16 色均吻合 DAT AC8h，第二人均吻合 MAN.COL 的 character×48；四十四份角色來源／CPU 覆蓋、完整圖層及十一個背景已獨立重組。收據為 duplicate-palette-source-v1/receipt.json／source-comparison.json。原來檔名碰巧同色的未知已由載入分支及正常取樣補足。

## HD 呈現契約與近似

沿用已確認的 B 畫風與原版雙人服裝配色。四份可丟棄比較覆蓋十一人，斬為白／紫、法蘭克為藍／綠，其他角色的替代色均按原表；原圖、透明度與圖集不重畫、不重編碼。印第安喬的正式比較使用正常待機來源 1；早期槽 0 的特效比較留作歷史。

HD 色彩轉移是明示的呈現近似。對原 PNG 的非透明 RGB，以原色盤 1..15 的距離建立權重 w=1／(d²+16)²，將加權的替代色差加到原 RGB；精確色盤錨點直接對應原替代色，其他值四捨五入及限於 0..255，alpha 保持。原來源表沒有同一 RGB 對應不同替代色的歧義。這保留已畫好的明暗細節，不稱為原版逐像素色彩或材質分割的證實。

LoadCharacters 對存在的 MAN.COL 核對固定 SHA、768 bytes 及六位元分量；缺檔維持原色包相容，無法使用同角色替代色；壞檔拒絕整組。素材版本維持 1／2／3，不新增公開原版色盤或持久設定。載入時建立不可變的替代影像視圖，Select 仍只讀；只在第二人、兩主角色相同、主色盤完整吻合原表時選替代圖。第一人、異角對戰及特效保留原有配色；未知色盤／來源仍整格原貌。WIN 沿同一已驗主色盤條件，不擅改姿態鍵或碰撞。

須驗十一人正常 fixture 的已登錄姿態、缺姿態保持回退、未知配色／錯角色拒絕、原色及 alpha 不變、原生同角色法蘭克的操作／切換，並抽樣第二人首勝。其他角色實際背景 HD、全部姿態／特效與平台實機不由本項完成。
