## 正常來源核對

已證實於取樣：`workplace/title-menu-source-v2` 保存正常啟動四次，各九份未點擊標題，共 36 份；另有十五份點擊後畫面，合計 51 份。工具為 Go 1.24.13、固定 dosgolem 副本及 Pillow 11.3.0。完整畫面色號、256 色盤及 RGB 分開保存，獨立 RGB 重組全部吻合。

SFNAME.CPM SHA-256 `9268d0093b84b67508ea1e2280ec5707c20b6d31a929bfd736b89e132a1842bc`。原檔偏移 0 為 little-endian 285×94，偏移 4 flag=0，不帶色盤；偏移 5 為 FFh RLE marker，偏移 6 起解析恰為 26,790 色號。TITLE.CPM 為 320×200、flag=1、色盤偏移 5、marker 偏移 773、資料偏移 774。原始檔偏移與 runtime／IDA 位址不混用；本輪沒有新增反組譯或宣稱已定位原載入函式。

TITLE 底圖加 SFNAME 透明色號 0 疊於原座標 18／96，再加第一按鈕外框 `[27,174,81,189)`、色號 51，36 份標題逐色號完全重組相同。若將疊圖的色號 0 當不透明，完整畫面不吻合。這證實目前固定來源的顯示內容，不等同可靠的 runtime 標題識別器。

已證實於取樣：原色盤 7..14 是同一八色的循環位移，目前觀察 shift 3／4；其他色除 51 外均吻合 TITLE.CPM。選取框色號 51 的實際 RGB 為 251／235／170，取樣一致，但其來源與完整變化契約仍未知。先前驗證器假設全色盤靜態而失敗，已依原收據分清原圖、循環色與框線，不忽略差異或凍結原版動畫。

單打、雙打普通點擊後都進原選角；設定進原設定畫面，未進選角；結束回 DOS、回傳碼 0。四個點擊中心為 x=50／120／190／260、y=181。這是取樣的有效點，不能當成完整命中矩形、鍵盤導航、游標或設定全部路徑已證實。
